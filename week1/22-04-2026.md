# Function Breakdown

## Function: maxSubarraySum()

### Purpose
Find the maximum sum of k consecutive elements using sliding window technique for optimal O(n) time complexity.

### Parameters
- `arr` (Array): Input array of numbers
- `k` (Number): Window size (number of consecutive elements)

### Return Value
- Maximum sum of k consecutive elements, or null if array too small

### Logic Explanation

**Step 1: Calculate sum of first window**
```javascript
let maxSum = 0;
for (let i = 0; i < k; i++) {
  maxSum += arr[i];
}
```
Adds first k elements to get initial sum.

**Step 2: Slide window through array**
```javascript
let s = 1;  // Start pointer
let e = k;  // End pointer

while (e < arr.length) {
  // Remove leftmost element, add new rightmost element
  tempSum = maxSum - arr[s - 1] + arr[e];
  
  // Update maxSum if larger
  if (tempSum > maxSum) {
    maxSum = tempSum;
  }
  
  // Slide window right
  e++;
  s++;
}
```

**Key Insight**: Instead of recalculating sum for each window, remove the leftmost element and add the new rightmost element.

# Algorithm Analysis

## Sliding Window Pattern

### What is Sliding Window?
A technique for problems involving contiguous subarrays or subsequences. Maintains a window of fixed or variable size that slides through the array.

### Why It's Powerful
- **Reduces complexity**: O(n*k) → O(n)
- **Elegant**: Simple logic, easy to understand
- **Versatile**: Works for many problems

### Common Sliding Window Applications
1. **Fixed-size window**: Max sum of k consecutive (this file)
2. **Variable-size window**: Longest substring without repeating chars
3. **Pointer-based**: Two-sum, container with most water
4. **Range queries**: Min/max in range

# Comparison: Naive vs Optimized

### Naive Approach (O(n*k))
```javascript
function maxSubarraySum_Naive(arr, k) {
  let maxSum = -Infinity;
  
  // For each starting position
  for (let i = 0; i <= arr.length - k; i++) {
    let sum = 0;
    
    // Calculate sum of k elements
    for (let j = i; j < i + k; j++) {
      sum += arr[j];
    }
    
    maxSum = Math.max(maxSum, sum);
  }
  
  return maxSum;
}
```

**Why slow**: Recalculates sum for each window (k additions per iteration)

### Optimized: Sliding Window (O(n))
```javascript
function maxSubarraySum(arr, k) {
  // Calculate first window
  let maxSum = 0;
  for (let i = 0; i < k; i++) {
    maxSum += arr[i];
  }
  
  let currentSum = maxSum;
  
  // Slide window
  for (let i = k; i < arr.length; i++) {
    // Remove left, add right
    currentSum = currentSum - arr[i - k] + arr[i];
    maxSum = Math.max(maxSum, currentSum);
  }
  
  return maxSum;
}
```

**Why fast**: Only 2 operations per window instead of k

### Performance Comparison

| Array Size | k | Naive | Optimized | Speedup |
|-----------|---|-------|-----------|---------|
| 1,000 | 10 | 10,000 ops | 1,000 ops | 10x |
| 10,000 | 100 | 1,000,000 ops | 10,000 ops | 100x |
| 100,000 | 1,000 | 100,000,000 ops | 100,000 ops | 1,000x |

# Code Improvements

### Issue in Current Code
```javascript
tempSum = 0;  // Reset to 0 every iteration - could be avoided
```

### Better Implementation
```javascript
function maxSubarraySum(arr, k) {
  if (arr.length < k || k <= 0) return null;
  
  // Calculate first window
  let windowSum = 0;
  for (let i = 0; i < k; i++) {
    windowSum += arr[i];
  }
  
  let maxSum = windowSum;
  
  // Slide window
  for (let i = k; i < arr.length; i++) {
    windowSum = windowSum - arr[i - k] + arr[i];
    maxSum = Math.max(maxSum, windowSum);
  }
  
  return maxSum;
}
```

**Improvements:**
- ✅ No tempSum reset
- ✅ Clear variable names
- ✅ Cleaner logic
- ✅ Input validation
