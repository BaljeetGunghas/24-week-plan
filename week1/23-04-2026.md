# Function Breakdown

## Function 1: twoSumSorted()

### Purpose
Find two indices in a sorted array that sum to target value.

### Parameters
- `arr` (Array): Sorted array of numbers
- `target` (Number): Target sum value

### Return Value
- Array of two indices `[left, right]` or null if no solution

### Logic Explanation

```javascript
function twoSumSorted(arr, target) {
  let left = 0;
  let right = arr.length - 1;
  
  while (left < right) {
    let sum = arr[left] + arr[right];
    
    if (sum === target) {
      return [left, right];  // Found pair
    } else if (sum < target) {
      left++;   // Sum too small, need larger number
    } else {
      right--; // Sum too large, need smaller number
    }
  }
  
  return null;  // No pair found
}
```

**Key Insight**: In sorted array, if sum is too small, move left pointer right to increase sum. If too large, move right pointer left to decrease sum.

### Dry Run

**Input**: `twoSumSorted([2, 7, 11, 15], 9)`

```
left=0, right=3: arr[0]+arr[3] = 2+15 = 17
  17 > 9? Yes → right--

left=0, right=2: arr[0]+arr[2] = 2+11 = 13
  13 > 9? Yes → right--

left=0, right=1: arr[0]+arr[1] = 2+7 = 9
  9 === 9? Yes → Return [0, 1]
```

### Time Complexity: O(n)
### Space Complexity: O(1)

## Function 2: reverseString()

### Purpose
Reverse an array/string in-place using two pointers.

### Logic Explanation

```javascript
function reverseString(arr) {
  let left = 0;
  let right = arr.length - 1;
  
  while (left < right) {
    // Swap left and right elements
    [arr[left], arr[right]] = [arr[right], arr[left]];
    
    left++;
    right--;
  }
  
  return arr;
}
```

### Dry Run

**Input**: `["h", "e", "l", "l", "o"]`

```
Iteration 1: Swap h ↔ o → ["o", "e", "l", "l", "h"]
Iteration 2: Swap e ↔ l → ["o", "l", "l", "e", "h"]
Iteration 3: Swap l ↔ l → ["o", "l", "l", "e", "h"] (no change)
left > right, exit

Result: ["o", "l", "l", "e", "h"]
```

### Time Complexity: O(n/2) = O(n)
### Space Complexity: O(1)

## Function 3: findMiddle()

### Purpose
Find middle element of array using fast and slow pointers (tortoise-hare algorithm).

### Incorrect Approach
```javascript
function findMiddle_Wrong(arr) {
  let slow = 0;
  let fast = 0;
  
  while (fast < arr.length - 2 || fast < arr.length - 1) {
    slow++;
    fast += 2;
  }
  
  return arr[slow];
}
```

**Problem**: Condition is confusing and doesn't handle edge cases properly.

### Correct Approach
```javascript
function findMiddle(arr) {
  let slow = 0;
  let fast = 0;
  
  // Fast moves 2 steps, slow moves 1 step
  while (fast < arr.length && arr[fast + 1] !== undefined) {
    slow++;
    fast += 2;
  }
  
  return arr[slow];
}
```

**Key Insight**: When fast pointer reaches end, slow pointer is at middle.

### Dry Run

**Input**: `[1, 2, 3, 4, 5]` (odd length, middle = 3)

```
slow=0, fast=0

Iteration 1:
  fast < 5 && arr[1] !== undefined? Yes
  slow=1, fast=2

Iteration 2:
  fast < 5 && arr[3] !== undefined? Yes
  slow=2, fast=4

Iteration 3:
  fast < 5 && arr[5] !== undefined? No (arr[5] is undefined)
  Exit

Return arr[2] = 3 ✓
```

**Input**: `[1, 2, 3, 4, 5, 6]` (even length)

```
Returns arr[2] = 3 (or could be designed to return 4)
```

### Time Complexity: O(n)
### Space Complexity: O(1)

## Function 4: checkPalindrome()

### Purpose
Check if a string is a palindrome using two pointers.

### Logic

```javascript
function checkPalindrome(str) {
  if (str.length === 0 || str.length === 1) {
    return true;
  }
  
  let left = 0;
  let right = str.length - 1;
  
  while (left < right) {
    let leftChar = str.charAt(left).toLowerCase();
    let rightChar = str.charAt(right).toLowerCase();
    
    if (leftChar !== rightChar) {
      return false;
    }
    
    left++;
    right--;
  }
  
  return true;
}
```

### Examples

| Input | Output | Reason |
|-------|--------|--------|
| "racecar" | true | Symmetric |
| "hello" | false | Not symmetric |
| "Ama" | true | Case-insensitive symmetric |
| "a" | true | Single character |
| "" | true | Empty |

### Time Complexity: O(n)
### Space Complexity: O(1)

## Function 5: validPalindromeII() - Advanced Challenge

### Purpose
Check if a string can be a palindrome after removing at most one character.

### Key Insight
When mismatch found, try two paths:
1. Skip left character and check if rest is palindrome
2. Skip right character and check if rest is palindrome

### Two Helper Functions

```javascript
function validPalindromeII(s) {
  let left = 0;
  let right = s.length - 1;
  
  while (left < right) {
    if (s[left] !== s[right]) {
      // When mismatch, try skipping either character
      return isPalindrome(s, left + 1, right) || 
             isPalindrome(s, left, right - 1);
    }
    left++;
    right--;
  }
  
  return true;
}

function isPalindrome(str, left, right) {
  while (left < right) {
    if (str[left] !== str[right]) {
      return false;
    }
    left++;
    right--;
  }
  return true;
}
```

### Dry Run

**Input**: `"abca"`

```
left=0, right=3: s[0]='a', s[3]='a' → Match, left=1, right=2
left=1, right=2: s[1]='b', s[2]='c' → Mismatch!

Try Option A: isPalindrome("abca", 2, 2)
  left=2, right=2: left < right? No
  return true ✓

Result: true (delete 'b' to get "aca")
```

### Time Complexity: O(n)
### Space Complexity: O(1)

# JavaScript Fundamentals

## Event Loop & Async Execution

### Execution Order Example

```javascript
console.log("1");

setTimeout(() => {
  console.log("2");
}, 0);

Promise.resolve().then(() => {
  console.log("3");
});

console.log("4");

// Output:
// 1
// 4
// 3
// 2
```

### Why This Order?

1. **Synchronous** (Call Stack):
   - `console.log("1")` → prints immediately
   - `console.log("4")` → prints immediately

2. **Microtask Queue** (Higher priority):
   - Promise `.then()` → prints after stack empties
   - `console.log("3")`

3. **Macrotask Queue** (Lower priority):
   - `setTimeout` → prints last
   - `console.log("2")`

### Queue Types

| Queue | Type | Examples |
|-------|------|----------|
| **Call Stack** | Synchronous | Function calls |
| **Microtask** | Async (High Priority) | Promises, .then(), async/await |
| **Macrotask** | Async (Low Priority) | setTimeout, setInterval |

### Execution Model

```
1. Execute all synchronous code
   ↓
2. Call Stack empty → Check Microtask Queue
   ↓
3. Microtask Queue empty → Check Macrotask Queue
   ↓
4. Execute one macrotask
   ↓
5. Check Microtask Queue again
   ↓
6. Repeat 4-5 until all queues empty
```

## Closures in JavaScript

### Example from File

```javascript
function createGame() {
  let score = 0;  // Private variable
  
  return {
    gainPoints: () => {
      score++;
      return score;
    },
  };
}

const game = createGame();
console.log(game.gainPoints());  // 1
console.log(game.gainPoints());  // 2
```

**What's happening:**
- `score` is trapped in closure
- Each call to `gainPoints()` accesses and modifies the same `score`
- `score` is private - cannot be accessed directly from outside

# Closure Pitfall Example

```javascript
const functions = [];

for (var i = 1; i <= 3; i++) {
  functions.push(() => console.log(i));
}

functions[0]();  // Logs 4 (not 1!)
functions[1]();  // Logs 4 (not 2!)
functions[2]();  // Logs 4 (not 3!)
```

**Why?** `var i` is hoisted to function scope, all closures reference same `i` which becomes 4 after loop.

**Fix:**
```javascript
for (let i = 1; i <= 3; i++) {  // Use let for block scope
  functions.push(() => console.log(i));
}

functions[0]();  // Logs 1 ✓
functions[1]();  // Logs 2 ✓
functions[2]();  // Logs 3 ✓
```

# Learning Notes

### Two Pointer Patterns

| Pattern | Use Case | Direction |
|---------|----------|-----------|
| **Opposite ends** | Sorted array sum, reversal | Inward |
| **Fast-slow** | Middle finding, cycle detection | Same direction |
| **Same direction** | Removing duplicates, partition | Forward |

### When to Use Each

1. **Opposite ends**: When array is sorted or order doesn't matter after processing
2. **Fast-slow**: When you need relative position tracking
3. **Same direction**: When modifying array while iterating

### Interview Preparation

- Two-pointer is fundamental; practice multiple variations
- Understand when each pattern applies
- Can combine with other techniques (recursion, dynamic programming)
- Always discuss time/space complexity
