# Function Breakdown

## Function 1: removeIndexNumber()

### Purpose
Removes an element at a specified index from an array and shifts all subsequent elements one position to the left.

### Parameters
- `arr` (Array): The input array to be modified
- `n` (Number): The index of the element to remove

### Return Value
- Modified array with element at index `n` removed, or error string "invalid input number" if index is out of bounds

### Logic Explanation

```javascript
const removeIndexNumber = (arr, n) => {
  // Step 1: Validate if index is within array bounds
  if (n > arr.length) {
    return "invalid input number";
  }
  
  // Step 2: Reduce array length by 1 (removes last element conceptually)
  arr.length = arr.length - 1;
  
  // Step 3: Shift all elements from index n one position left
  for (i = n; i <= arr.length; i++) {
    if (i < arr.length) {
      if (i === arr.length) {
        arr[i] = arr[i];  // This condition is redundant
      } else {
        arr[i] = arr[i + 1];  // Move next element to current position
      }
    }
  }
  
  // Step 4: Return modified array
  return arr;
};
```

**How it works:**
1. First validates that the index isn't out of bounds
2. Decreases array length to conceptually remove the last element
3. Uses a loop starting from index `n` to shift all elements left
4. Each element takes the value of the element to its right
5. The last position naturally becomes undefined due to length reduction

### Dry Run Example

**Input**: `removeIndexNumber([1, 2, 3], 1)`

```
Initial array: [1, 2, 3] (length = 3)

Step 1: Index validation - 1 <= 3 ✓

Step 2: arr.length = 2 (array conceptually has 2 slots)

Step 3: Loop iteration (i = 1 to 2)
  i = 1: arr[1] = arr[2] = 3  →  [1, 3, 3]
  i = 2: 2 < 2? No, loop ends

Return: [1, 3]
```

### Edge Cases

1. **Invalid index**: `removeIndexNumber([1, 2, 3], 5)` → Returns "invalid input number"
2. **First element**: `removeIndexNumber([1, 2, 3], 0)` → Returns [2, 3]
3. **Single element**: `removeIndexNumber([1], 0)` → Returns []
4. **Empty array**: `removeIndexNumber([], 0)` → Returns []

### Time Complexity
**O(n)** - In the worst case (removing first element), all n elements need to be shifted one position left.

### Space Complexity
**O(1)** - No extra space is used; the array is modified in-place.

## Function 2: getPrefixSum()

### Purpose
Creates and returns a new array where each element is the cumulative sum of all elements up to and including that position in the original array.

### Parameters
- `arr` (Array): Input array of numbers

### Return Value
- Array with prefix sum values, or error string if array is invalid

### Logic Explanation

```javascript
const getPrefixSum = (arr) => {
  // Step 1: Input validation
  if (arr.length < 1) {
    return "provide a valid array";
  }
  
  // Step 2: Handle single element case
  if (arr.length === 1) {
    return arr;  // Single element is its own prefix sum
  }
  
  // Step 3: Create result array
  const prefArray = [];
  
  // Step 4: First element of prefix sum equals first element of input
  prefArray[0] = arr[0];
  
  // Step 5: Calculate prefix sum for remaining elements
  for (let i = 1; i < arr.length; i++) {
    // Each position = previous prefix sum + current element
    prefArray[i] = prefArray[i - 1] + arr[i];
  }
  
  // Step 6: Return result
  return prefArray;
};
```

**Key Insight**: Prefix sum builds upon previous results - `prefix[i] = prefix[i-1] + arr[i]`

### Dry Run Example

**Input**: `getPrefixSum([1, 2, 3, 4, 5])`

```
Step 1: Validation ✓
Step 2: Length > 1 ✓
Step 3: prefArray = []
Step 4: prefArray[0] = 1
  → prefArray = [1]

Step 5: Loop iteration
  i = 1: prefArray[1] = prefArray[0] + arr[1] = 1 + 2 = 3
    → prefArray = [1, 3]
  i = 2: prefArray[2] = prefArray[1] + arr[2] = 3 + 3 = 6
    → prefArray = [1, 3, 6]
  i = 3: prefArray[3] = prefArray[2] + arr[3] = 6 + 4 = 10
    → prefArray = [1, 3, 6, 10]
  i = 4: prefArray[4] = prefArray[3] + arr[4] = 10 + 5 = 15
    → prefArray = [1, 3, 6, 10, 15]

Return: [1, 3, 6, 10, 15]
```

### Edge Cases

1. **Empty array**: `getPrefixSum([])` → "provide a valid array"
2. **Single element**: `getPrefixSum([5])` → [5]
3. **Negative numbers**: `getPrefixSum([1, -2, 3])` → [1, -1, 2]
4. **All zeros**: `getPrefixSum([0, 0, 0])` → [0, 0, 0]

### Time Complexity
**O(n)** - Must iterate through each element once to calculate cumulative sum.

### Space Complexity
**O(n)** - Creates a new array of size n to store prefix sums.

### Use Cases
- Range sum queries: Finding sum between indices [i, j] in O(1) time
- Building histograms
- 2D matrix sum queries
- Finding equilibrium index

## Function 3: getSecondMax()

### Purpose
Finds and returns the second largest number in an array in a single pass without sorting.

### Parameters
- `arr` (Array): Input array of numbers

### Return Value
- Second largest number, or error string if array has fewer than 2 elements

### Logic Explanation

```javascript
function getSecondMax(arr) {
  // Step 1: Validate array has at least 2 elements
  if (arr.length < 2) {
    return "please provide valid array";
  }
  
  // Step 2: Initialize both max and secondmax to first element
  let max = arr[0];
  let secondmax = arr[0];
  
  // Step 3: Iterate through remaining elements
  for (let i = 1; i < arr.length; i++) {
    const item = arr[i];
    
    // Step 4: If current item is greater than max
    if (item > max) {
      // Previous max becomes second max
      secondmax = max;
      // Update max to current item
      max = item;
    } 
    // Step 5: Else if current item is between secondmax and max
    else if (item > secondmax) {
      // Update second max
      secondmax = item;
    }
    // If item < secondmax, do nothing
  }
  
  // Step 6: Return second maximum
  return secondmax;
}
```

**Key Logic**: Track two values simultaneously - maintain both max and secondmax as we scan through the array.

### Dry Run Example

**Input**: `getSecondMax([23, 43, 35, 74, 75, 34, 65])`

```
Step 1: Validation ✓ (length >= 2)
Step 2: max = 23, secondmax = 23

Step 3: Loop iterations
  i = 1, item = 43:
    43 > 23? Yes → secondmax = 23, max = 43
    max = 43, secondmax = 23
  
  i = 2, item = 35:
    35 > 43? No
    35 > 23? Yes → secondmax = 35
    max = 43, secondmax = 35
  
  i = 3, item = 74:
    74 > 43? Yes → secondmax = 43, max = 74
    max = 74, secondmax = 43
  
  i = 4, item = 75:
    75 > 74? Yes → secondmax = 74, max = 75
    max = 75, secondmax = 74
  
  i = 5, item = 34:
    34 > 75? No
    34 > 74? No (skip)
    max = 75, secondmax = 74
  
  i = 6, item = 65:
    65 > 75? No
    65 > 74? No (skip)
    max = 75, secondmax = 74

Return: 74
```

### Edge Cases

1. **Two elements**: `getSecondMax([5, 3])` → 3
2. **Two elements (reversed)**: `getSecondMax([3, 5])` → 3
3. **All same numbers**: `getSecondMax([5, 5, 5, 5])` → 5
4. **Duplicates at max**: `getSecondMax([10, 20, 20, 15])` → 15
5. **Large gap**: `getSecondMax([1, 100, 2, 50])` → 50
6. **Negative numbers**: `getSecondMax([-5, -2, -10])` → -5

### Important Note on Duplicates
The current implementation doesn't handle the case where max appears multiple times (which might be desired). If you want to exclude duplicates, uncomment the commented code:

```javascript
// Exclude duplicates version:
else if (item > secondmax && item !== max) {
  secondmax = item;
}
```

### Time Complexity
**O(n)** - Single pass through the array, constant time operations in each iteration.

### Space Complexity
**O(1)** - Only two variables (max and secondmax) are used regardless of input size.

## Function 4: moveZeroAtLast()

### Purpose
Moves all zero elements to the end of an array while maintaining the relative order of non-zero elements. Uses the two-pointer technique for in-place manipulation.

### Parameters
- `arr` (Array): Input array containing zeros and non-zero elements

### Return Value
- Modified array with all zeros moved to the end

### Logic Explanation

```javascript
function moveZeroAtLast(arr) {
  // Step 1: Handle single element case
  if (arr.length === 1) {
    return arr;
  }
  
  // Step 2: Initialize two pointers
  let s = 0;           // Start pointer from beginning
  let e = arr.length - 1;  // End pointer from end
  
  // Step 3: Two-pointer approach - bring pointers closer
  while (s < e) {
    // Step 4: If element at start is zero
    if (arr[s] === 0) {
      // Step 5: Swap zero with element at end
      const temp = arr[s];
      arr[s] = arr[e];
      arr[e] = temp;
      
      // Step 6: Move both pointers inward
      s++;
      e--;
    } else {
      // Step 7: If not zero, just move start pointer
      s++;
    }
  }
  
  // Step 8: Return modified array
  return arr;
}
```

**Core Concept**: Use two pointers approaching each other - swap zeros found at the start with non-zeros at the end.

### Dry Run Example

**Input**: `moveZeroAtLast([0, 1, 0, 3, 12])`

```
Initial: [0, 1, 0, 3, 12], s=0, e=4

Iteration 1:
  arr[0] = 0? Yes
  Swap arr[0] ↔ arr[4]: [12, 1, 0, 3, 0]
  s=1, e=3

Iteration 2:
  arr[1] = 1? No (not 0)
  s=2, e=3

Iteration 3:
  arr[2] = 0? Yes
  Swap arr[2] ↔ arr[3]: [12, 1, 3, 0, 0]
  s=3, e=2

Loop condition: s < e? 3 < 2? No → Exit

Return: [12, 1, 3, 0, 0]
```

### Edge Cases

1. **No zeros**: `moveZeroAtLast([1, 2, 3])` → [1, 2, 3]
2. **All zeros**: `moveZeroAtLast([0, 0, 0])` → [0, 0, 0]
3. **Single element zero**: `moveZeroAtLast([0])` → [0]
4. **Single element non-zero**: `moveZeroAtLast([5])` → [5]
5. **Zeros at end**: `moveZeroAtLast([1, 2, 0, 0])` → [1, 2, 0, 0]
6. **All zeros except last**: `moveZeroAtLast([0, 0, 0, 1])` → [1, 0, 0, 0]

### Time Complexity
**O(n)** - Each element is visited at most once. Two pointers traverse the array from both ends.

### Space Complexity
**O(1)** - In-place manipulation using only two pointer variables. No extra data structures needed.

- Sorting: O(n log n) time - SLOWER

```javascript
const getPrefixSum = (arr) => {
```

## Function 4: moveZeroAtLast()

### Optimized Stable Version (Preserves Order)
```javascript
const moveZeroAtLastStable = (arr) => {
  const nonZeros = arr.filter(num => num !== 0);
  const zeros = new Array(arr.length - nonZeros.length).fill(0);
  return [...nonZeros, ...zeros];
};
```

**Pros:**
- ✅ Maintains relative order perfectly
- ✅ More readable
- ✅ Stable algorithm

**Cons:**
- ❌ Uses O(n) extra space
- ❌ Creates new array

### Alternative: Stable Two-Pointer (O(n) time, O(1) space)
```javascript
const moveZeroAtLastStableInPlace = (arr) => {
  let writeIndex = 0;
  
  // First pass: move all non-zeros
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] !== 0) {
      arr[writeIndex] = arr[i];
      writeIndex++;
    }
  }
  
  // Second pass: fill remaining with zeros
  for (let i = writeIndex; i < arr.length; i++) {
    arr[i] = 0;
  }
  
  return arr;
};
```

**Advantages:**
- ✅ O(1) space
- ✅ O(n) time (two passes)
- ✅ Maintains order
- ✅ More readable than two-pointer swap

```
prefArray[3] = 7 + 3 = 10
```

**Output:** `[2, 6, 7, 10]`

**Application:** Query "sum from index 1 to 3" = prefArray[3] - prefArray[0] = 10 - 2 = 8 (which is 4 + 1 + 3)

## Example 4: moveZeroAtLast

**Input:**
```javascript
array = [0, 1, 0, 3, 12]
```

**Execution:**
```
s=0, e=4: arr[0]=0
  Swap: [12, 1, 0, 3, 0]
  s=1, e=3

s=1, e=3: arr[1]=1 (not 0)
  s=2

s=2, e=3: arr[2]=0
  Swap: [12, 1, 3, 0, 0]
  s=3, e=2

s=3, e=2: 3 < 2? No, exit
```

**Output:** `[12, 1, 3, 0, 0]`

**Note:** Non-zero elements maintain relative order, but absolute positions change due to swaps.
