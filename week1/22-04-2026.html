Challenge: Maximum Subarray Sum

Find Maximum Sum of K Consecutive Numbers

Objective: Given array and window size k, find maximum sum of k consecutive elements.

Example: [2, 1, 5, 1, 3, 2], k=3 → Window sums: 8, 7, 9, 6 → Output: 9

  • Fundamental sliding window pattern
  • Time optimization from O(n*k) to O(n)
  • Essential for many DSA problems

Function: maxSubarraySum()

Purpose

Find maximum sum of k consecutive elements using sliding window technique for optimal O(n) time complexity instead of naive O(n*k) approach.

How It Works

  1. 1 Calculate sum of first window (first k elements)
  2. 2 Store as initial maximum
  3. 3 Slide window: remove leftmost, add new rightmost
  4. 4 Update maximum if new sum is larger
  5. 5 Repeat until end of array

Visual Example

Code Example

function maxSubarraySum(arr, k) {
  if (arr.length < k || k <= 0) return null;

  // Calculate sum of first window
  let windowSum = 0;
  for (let i = 0; i < k; i++) {
    windowSum += arr[i];
  }

  let maxSum = windowSum;

  // Slide window through rest of array
  for (let i = k; i < arr.length; i++) {
    // Remove leftmost element, add new rightmost element
    windowSum = windowSum - arr[i - k] + arr[i];
    maxSum = Math.max(maxSum, windowSum);
  }

  return maxSum;
}

Sliding Window Concept

What is Sliding Window?

A technique for problems involving contiguous subarrays or subsequences. A window of fixed or variable size slides through the data, processing each section efficiently.

When to Use Sliding Window

  • "Find max/min in k consecutive elements"
  • "Longest substring without repeating characters"
  • "Average of all contiguous subarrays"
  • "Number of subarrays with sum equal to k"
  • "Container with most water"

Key Takeaways

  • Core Trick: Remove old element, add new element instead of recalculating
  • Time Reduction: O(n*k) becomes O(n) - massive improvement
  • Pattern Recognition: Look for "k consecutive" hints in problem statement
  • Versatility: Works for fixed and variable window sizes
