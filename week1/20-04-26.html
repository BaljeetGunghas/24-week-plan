Function 1: removeIndexNumber()

Purpose

Removes an element at a specified index and shifts subsequent elements left by one position. Demonstrates manual array manipulation without built-in methods.

How It Works

  1. 1 Validate that the index is within bounds
  2. 2 Reduce array length by 1
  3. 3 Loop from index n to shift elements left
  4. 4 Each element takes value of element to its right
  5. 5 Return the modified array

Visual Example

Code Example

const removeIndexNumber = (arr, n) => {
  if (n > arr.length) return "invalid input number";

  arr.length = arr.length - 1;  // Reduce length

  for (let i = n; i < arr.length; i++) {
    arr[i] = arr[i + 1];        // Shift elements left
  }

  return arr;
};

Step-by-Step Dry Run

Input: removeIndexNumber([1, 2, 3], 1) ├─ Initial: [1, 2, 3] (length = 3) ├─ After length reduction: [1, 2, 3] (length = 2) ├─ Iteration (i=1): arr[1] = arr[2] = 3 → [1, 3, 3] ├─ Iteration (i=2): Loop ends (2 < 2? No) └─ Return: [1, 3] ✓

Complexity Analysis

Time Complexity

O(n)

Worst case: removing first element shifts all n items

Space Complexity

O(1)

In-place modification, no extra data structures

Function 2: getPrefixSum()

Purpose

Create an array where each element is the sum of all elements up to that index. Essential pattern for optimizing range queries.

Visual Example

Code Example

const getPrefixSum = (arr) => {
  if (!Array.isArray(arr) || arr.length === 0) {
    return "provide a valid array";
  }

  const prefArray = [arr[0]];

  for (let i = 1; i < arr.length; i++) {
    prefArray[i] = prefArray[i - 1] + arr[i];  // Build on previous sum
  }

  return prefArray;
};

Key Applications

Range Queries

Find sum between any two indices in O(1) time

Subarray Sum

Find subarrays with specific sum efficiently

Equilibrium

Find balance points in arrays

Complexity Analysis

Time Complexity

O(n)

Single pass through array

Space Complexity

O(n)

New array of same size

Function 3: getSecondMax()

Purpose

Find the second largest number in a single pass by tracking both maximum and second maximum values simultaneously.

Visual Example

Code Example

function getSecondMax(arr) {
  if (arr.length < 2) return "please provide valid array";

  let max = arr[0];
  let secondMax = arr[0];

  for (let i = 1; i < arr.length; i++) {
    if (arr[i] > max) {
      secondMax = max;        // Previous max becomes second max
      max = arr[i];           // Update max
    } else if (arr[i] > secondMax) {
      secondMax = arr[i];     // Update only second max
    }
  }

  return secondMax;
}

Complexity Analysis

Time Complexity

O(n)

Single pass, no sorting needed

Space Complexity

O(1)

Only 2 variables used

Why This is Better Than Sorting

Approach Time Space Efficiency
Our Method O(n) O(1) ✓ Optimal
Sort First O(n log n) O(n) ✗ Slower
Heap Method O(n + k log n) O(k) ~ Good for large k

Function 4: moveZeroAtLast()

Purpose

Move all zeros to the end of an array using the two-pointer technique, maintaining non-zero element order with O(1) space complexity.

Two-Pointer Visualization

Code Example

function moveZeroAtLast(arr) {
  if (arr.length === 1) return arr;

  let s = 0;                    // Start pointer
  let e = arr.length - 1;       // End pointer

  while (s < e) {
    if (arr[s] === 0) {         // Found zero at start
      [arr[s], arr[e]] = [arr[e], arr[s]];  // Swap
      s++;
      e--;
    } else {
      s++;                      // Move start if not zero
    }
  }

  return arr;
}

Detailed Step-by-Step Execution

Input: [0, 1, 0, 3, 12] Initial: s=0, e=4, array = [0, 1, 0, 3, 12] Iteration 1: (s < e? 0 < 4? YES) arr[0]===0? YES → Swap arr[0] ↔ arr[4]: [12, 1, 0, 3, 0] → s=1, e=3 Iteration 2: (s < e? 1 < 3? YES) arr[1]===0? NO (it's 1) → s=2, e=3 Iteration 3: (s < e? 2 < 3? YES) arr[2]===0? YES → Swap arr[2] ↔ arr[3]: [12, 1, 3, 0, 0] → s=3, e=2 Loop Check: (s < e? 3 < 2? NO) → EXIT Final Result: [12, 1, 3, 0, 0] ✓

Complexity Analysis

Time Complexity

O(n)

Two pointers traverse array once

Space Complexity

O(1)

In-place swapping, no extra space

Why Two-Pointer is Optimal

Approach Time Space Stable Notes
Two Pointers (Our Method) O(n) O(1) No Efficient but changes order due to swaps
Two Pass (Write Pointer) O(n) O(1) Yes ✓ Stable & maintains relative order
Filter + Concat O(n) O(n) Yes ✓ Readable but wastes space

Key Takeaways

  • Two-Pointer Technique: Move pointers from opposite ends toward center for efficient in-place operations
  • Prefix Sum Pattern: Build solutions iteratively to optimize range queries from O(n) to O(1)
  • Tracking Multiple Values: Maintain running maximum/second maximum with constant space
  • Space-Time Tradeoffs: Sometimes O(n) space gives cleaner code, but O(1) space is more elegant
  • Single Pass Optimization: Always look for ways to solve in one pass instead of multiple
