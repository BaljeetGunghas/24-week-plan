## HTTP Server Creation

### Creating the Server

```javascript
const http = require("http");

const server = http.createServer((req, res) => {
  // req = incoming request from client
  // res = outgoing response to send to client
  
  res.setHeaders = ("content-type", "application/json");
  console.log(req.url, req.method);
  
  // Handle routes...
});

server.listen(3000, () => {
  console.log(`Server running on port 3000`);
});
```

**Components:**
- `req.url`: The path client requested (e.g., "/profile")
- `req.method`: HTTP method used (GET, POST, PUT, DELETE)
- `res.statusCode`: HTTP status (200 = OK, 404 = Not Found)
- `res.end()`: Finish and send response

### POST Request Handler - Streaming Data

```javascript
else if (req.url === "/profile-update" && req.method === "POST") {
  let body = "";
  
  // Event 1: Data arrives in chunks
  req.on("data", (chunk) => {
    body += chunk.toString();  // Accumulate chunks
    console.log(body);
  });
  
  // Event 2: All data received
  req.on("end", () => {
    const data = JSON.parse(body);  // Convert JSON to object
    console.log(data);
    
    res.end(JSON.stringify({
      data,
      message: `Target updated to ${data.target}`,
    }));
  });
}
```

**Why Streaming?**
- HTTP request body comes in **chunks**, not all at once
- Large files would consume too much memory if loaded entirely
- Listen to "data" event for each chunk
- Listen to "end" event when complete

# Event-Driven Architecture

### Request Events

| Event | When | Use Case |
|-------|------|----------|
| 'data' | Chunk of body received | Accumulate POST data |
| 'end' | All body received | Start processing |
| 'error' | Network error | Error handling |

### Example: Data Event Sequence

**Sending 1000 bytes in chunks:**

```
Chunk 1 (256 bytes) → 'data' event fired
Chunk 2 (256 bytes) → 'data' event fired
Chunk 3 (256 bytes) → 'data' event fired
Chunk 4 (232 bytes) → 'data' event fired
                    → 'end' event fired (all received)
```

# Issues in the Code

### Issue 1: Typo in setHeaders
```javascript
// ❌ Wrong
res.setHeaders = ("content-type", "application/json");

// ✅ Correct
res.setHeader("content-type", "application/json");
```

`setHeaders` (assignment) vs `setHeader` (method call)

### Issue 2: setHeader Function

- `setHeader(key, value)`: Set ONE header
- Should be called before `res.end()`
- Multiple headers can be set

```javascript
// ✅ Correct usage
res.setHeader("content-type", "application/json");
res.setHeader("x-custom-header", "value");
res.statusCode = 200;
res.end(JSON.stringify({ message: "OK" }));
```

### Issue 3: No Error Handling
```javascript
// ❌ No error handling for invalid JSON
const data = JSON.parse(body);

// ✅ With error handling
try {
  const data = JSON.parse(body);
} catch (err) {
  res.statusCode = 400;
  res.end(JSON.stringify({ error: "Invalid JSON" }));
}
```

### Core Concepts

1. **HTTP Server**: Listens on port, handles requests
2. **Routing**: Path + Method determines response
3. **Streaming**: Data comes in chunks, accumulate then process

### When to Use Native HTTP vs Framework

**Native HTTP (this file):**
- ✅ Simple APIs
- ✅ Learning purpose
- ❌ Verbose for complex apps

**Express/Fastify Framework:**
- ✅ Cleaner syntax
- ✅ Built-in middleware
- ✅ Auto body parsing
- ✅ Better routing

# Interview Notes

### Q1: "How does HTTP request body streaming work?"

**Answer:**
- Request body comes in chunks for memory efficiency
- Listen to 'data' event for each chunk
- Accumulate chunks into a buffer
- Listen to 'end' event when complete
- Then parse the accumulated data

### Q2: "Why use streams instead of loading everything?"

**Answers:**
- ✅ Memory efficient (don't load entire file)
- ✅ Can start processing before all data arrives
- ✅ Better for large files
- ✅ Scalability

### Q3: "What's the difference between statusCode and statusMessage?"

**Answer:**
- `statusCode` (200): Number code for programmatic use
- `statusMessage` ("OK"): Human-readable explanation
- Client cares about code; both sent in response

### Better Error Handling

```javascript
const server = http.createServer((req, res) => {
  try {
    res.setHeader("content-type", "application/json");
    
    if (req.url === "/profile" && req.method === "GET") {

      res.statusCode = 404;
      res.end(JSON.stringify({ error: "Not Found" }));

  }
```
