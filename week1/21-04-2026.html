Function 1: moveZeroAtLast() - Write Pointer

Purpose

Move all zeros to end while maintaining order of non-zero elements using write-pointer approach. Differs from two-pointer swap method by maintaining stability and better cache locality.

How It Works

  1. 1 Single pointer tracks where next non-zero should be written
  2. 2 Iterate through entire array left to right
  3. 3 When non-zero found, swap with write pointer position
  4. 4 Advance write pointer after each non-zero
  5. 5 Skip zeros naturally without special handling

Visual Example

Code Example

function moveZeroAtLast(arr) {
  if (arr.length === 1) return arr;

  let count = 0;  // Write pointer

  for (let i = 0; i < arr.length; i++) {
    if (arr[i] !== 0) {
      // Swap current with write position
      const temp = arr[count];
      arr[count] = arr[i];
      arr[i] = temp;
      count++;
    }
  }

  return arr;
}

Step-by-Step Dry Run

Input: moveZeroAtLast([0, 1, 0, 3, 12]) count = 0 i=0: arr[0]=0 (is zero, skip) i=1: arr[1]=1 (not zero) Swap arr[0]↔arr[1]: [1, 0, 0, 3, 12] → count=1 i=2: arr[2]=0 (is zero, skip) i=3: arr[3]=3 (not zero) Swap arr[1]↔arr[3]: [1, 3, 0, 0, 12] → count=2 i=4: arr[4]=12 (not zero) Swap arr[2]↔arr[4]: [1, 3, 12, 0, 0] → count=3 Return: [1, 3, 12, 0, 0] ✓

Understanding the Call Stack

What is the Call Stack?

The call stack is a data structure (LIFO - Last In, First Out) that keeps track of function calls during program execution. When a function is called, it's pushed onto the stack, and when it returns, it's popped off.

Call Stack Example

function greet() { console.log("Hello!"); // Step 3 } function start() { greet(); // Step 2 } start(); // Step 1 Stack Evolution: Step 1: Step 2: Step 3: Step 4: ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐ │ start │ │ greet │ │ (ready) │ │ (empty) │ ├─────────┤ ├─────────┤ ├─────────┤ ├─────────┤ │ Global │ │ start │ │ start │ │ Global │ ├─────────┤ ├─────────┤ ├─────────┤ ├─────────┤ │ │ │ Global │ │ Global │ │ │ └─────────┘ └─────────┘ └─────────┘ └─────────┘

Stack Overflow: Infinite Recursion

function recursive() { return recursive(); // No base case! } console.log(recursive()); // RangeError: Maximum call stack size exceeded What happens: 1. Each function call pushes onto stack 2. Stack has maximum size (~15,000-30,000 calls) 3. Exceeding limit causes "Stack Overflow" error 4. Browser/Node.js crashes that execution

Hoisting in JavaScript

What is Hoisting?

Hoisting is JavaScript's behavior of moving declarations to the top of their scope before code execution. IMPORTANT: Only declarations are hoisted, NOT assignments!

Variable Hoisting Comparison

var - Hoisted AND Initialized as undefined

console.log(name);  // undefined (not an error!)
var name = "Baljeet";

// What happens behind scenes:
var name;  // Declaration hoisted
console.log(name);  // undefined
name = "Baljeet";  // Assignment stays in place

let and const - Hoisted but NOT Initialized

console.log(x);  // ❌ ReferenceError: Cannot access 'x' before initialization
let x = 10;

// What happens:
// Temporal Dead Zone starts here
// console.log(x);  // ❌ Error in this zone!
let x = 10;  // ✨ TDZ ends here
console.log(x);  // ✅ Works, logs 10

Function Hoisting

Function Declaration - FULLY Hoisted

sayHi();  // ✅ Works! Logs "Hi Navi!"

function sayHi() {
  console.log("Hi Navi!");
}

Why: Entire function declaration (including body) is hoisted

Function Expression - Only var is Hoisted

sayBye();  // ❌ Error

var sayBye = function() {
  console.log("Bye!");
};

Why: Only var sayBye is hoisted as undefined, not the function body

Temporal Dead Zone (TDZ)

What is TDZ?

The Temporal Dead Zone is the time between when a variable enters its scope and when it's declared. Accessing let/const variables in the TDZ throws a ReferenceError, preventing bugs from var-like hoisting behavior.

TDZ Visualization

{ // ← TDZ STARTS HERE // console.log(user); // ❌ ReferenceError // Still in TDZ... // if (true) console.log(user); // ❌ Still in TDZ let user = "Baljeet"; // ← TDZ ENDS HERE console.log(user); // ✅ Works: "Baljeet" if (true) { console.log(user); // ✅ Works (outer scope) } }

Nested Scope TDZ - Common Mistake

let x = "Global"; function checkScope() { console.log(x); // ❌ ReferenceError! let x = "Local"; } checkScope(); Why error: The 'let x' inside function creates NEW TDZ for that block, shadowing the global x throughout the function!

Challenge 5: Range Sum Query

Problem

Given array and multiple queries (i, j), return sum of elements from index i to j in O(1) time using prefix sums.

class RangeSum {
  constructor(nums) {
    this.prefix = [nums[0]];
    for (let i = 1; i < nums.length; i++) {
      this.prefix[i] = this.prefix[i - 1] + nums[i];
    }
  }

  query(i, j) {
    if (i === 0) return this.prefix[j];
    return this.prefix[j] - this.prefix[i - 1];
  }
}

// Usage
const rangeSum = new RangeSum([1, 2, 3, 4]);
console.log(rangeSum.query(1, 3));  // 2+3+4 = 9
console.log(rangeSum.query(0, 2));  // 1+2+3 = 6
Preprocessing

O(n) time, O(n) space

Each Query

O(1) time

Challenge 6: Find Pivot Index

Problem

Find index where sum of left elements equals sum of right elements. Example: [1, 7, 3, 6, 5, 6] → Index 3

Optimized Approach (O(n) time, O(1) space)

function findPivotIndex(arr) {
  let totalSum = 0;
  for (let num of arr) totalSum += num;

  let leftSum = 0;
  for (let i = 0; i < arr.length; i++) {
    const rightSum = totalSum - leftSum - arr[i];

    if (leftSum === rightSum) return i;
    leftSum += arr[i];
  }

  return -1;  // No pivot found
}

Dry Run Example

Input: [1, 7, 3, 6, 5, 6] totalSum = 28, leftSum = 0 i=0: rightSum = 28-0-1 = 27, 0≠27 → leftSum=1 i=1: rightSum = 28-1-7 = 20, 1≠20 → leftSum=8 i=2: rightSum = 28-8-3 = 17, 8≠17 → leftSum=11 i=3: rightSum = 28-11-6 = 11, 11===11 ✅ Return 3 Index 3 is the pivot!

Challenge 7: Running Sum In-Place

function getRunningSum(arr) {
  for (let i = 1; i < arr.length; i++) {
    arr[i] = arr[i - 1] + arr[i];  // Modify in-place
  }
  return arr;
}

Challenge 8: Highest Altitude

function findHighestAltitude(gain) {
  let maxAltitude = 0;
  let currentAltitude = 0;

  for (let i = 0; i < gain.length; i++) {
    currentAltitude += gain[i];
    if (currentAltitude > maxAltitude) {
      maxAltitude = currentAltitude;
    }
  }

  return maxAltitude;
}

// Test: [-5, 1, 5, 0, -7] → 1
// Complexity: O(n) time, O(1) space
