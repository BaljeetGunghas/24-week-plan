Challenge 1: Sliding Window - Longest Substring

Problem Statement

Input: "abcabcbb"

Output: 3 (longest substring: "abc")

Complexity: O(n) time, O(k) space (k = charset size)

The Sliding Window Pattern

Core Idea: Maintain a window [left, right] that contains only unique characters. Expand right, shrink left when duplicate found.

Implementation

function longestSubstringWithoutRepeatingCharacters(s) {
    if (s.length === 0) return 0;

    const charMap = new Map();  // Store char → last seen index
    let left = 0;
    let maxLength = 0;

    for (let right = 0; right < s.length; right++) {
        const char = s[right];

        // If char seen before and within current window
        if (charMap.has(char)) {
            // Jump left pointer past the duplicate
            left = Math.max(left, charMap.get(char) + 1);
        }

        // Update char's latest position
        charMap.set(char, right);

        // Calculate window length
        const windowLength = right - left + 1;
        maxLength = Math.max(maxLength, windowLength);
    }

    return maxLength;
}

const result = longestSubstringWithoutRepeatingCharacters("abcabcbb");
console.log(result);  // Output: 3
