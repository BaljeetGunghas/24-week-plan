Challenge 1: Group Anagrams

Problem Statement

Input: ["eat", "tea", "tan", "ate", "nat", "bat"]

Output: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]

Key Insight: Anagrams have the same letters, so when sorted, they become identical.

The Core Logic

Aha Moment: If you sort the letters in "eat", "tea", and "ate", they all become "aet". Use this as the hash key!

Solution

function groupAnagrams(strs) {
    const map = new Map();

    for (let i = 0; i < strs.length; i++) {
        const word = strs[i];

        // Step 1: Sort letters to create unique key
        // "eat" → "aet", "tea" → "aet", "ate" → "aet"
        const key = word.split("").sort().join("");

        // Step 2: Check if key exists
        if (map.has(key)) {
            // Add to existing group
            map.get(key).push(word);
        } else {
            // Create new group
            map.set(key, [word]);
        }
    }

    // Step 3: Convert map to array
    return Array.from(map.values());
}

const result = groupAnagrams(["eat", "tea", "tan", "ate", "nat", "bat"]);
console.log(result);
