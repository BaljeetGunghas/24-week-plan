## 🏗️ **Project Documentations**

### **CloudDrop SaaS Project**
A complete file upload application with React frontend + Express backend + MongoDB database.

**What You'll Learn:**
- React component architecture
- Redux state management with persistence
- Express.js REST APIs
- MongoDB schema design
- Cloudinary integration
- File upload flow (client → server → storage)
- Authentication with JWT
- User dashboard & file management
- 50+ system design interview questions

**Technologies:**
- Frontend: React 19.2.6, Redux Toolkit, Tailwind CSS
- Backend: Express.js, Node.js, Mongoose
- Database: MongoDB
- Cloud: Cloudinary, JWT
- Testing: Jest, React Testing Library

---

### **File Upload Streaming API**
A production-grade Node.js streaming API demonstrating professional file upload handling.

**What You'll Learn:**
- Node.js streams (Readable, Writable, Transform)
- Backpressure handling & memory optimization
- Busboy multipart parsing
- Error handling & cleanup logic
- 50 interview questions on:
  - Stream architecture
  - Backpressure mechanics
  - Production optimization
  - Distributed systems
  - Security considerations

**Key Concepts:**
- Memory-efficient file uploads (4MB per request regardless of file size)
- Handling 50+ concurrent uploads
- Cleanup on connection abort
- Resumable uploads
- Virus scanning integration
- Rate limiting & quotas
