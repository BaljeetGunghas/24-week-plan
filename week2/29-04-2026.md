# Problem: Smallest Subarray with Sum ≥ Target

**Input**: `[2, 3, 1, 2, 4, 3]`, target = 7  
**Output**: 2 (subarray [4, 3])

## Approach 1: Brute Force - O(n²)

```javascript
function smallestSubarray(target, arr) {
  let smallestLength = arr.length;
  
  for (let i = 0; i < arr.length; i++) {
    let sum = arr[i];
    
    for (let j = i + 1; j < arr.length; j++) {
      sum += arr[j];
      
      if (sum >= target) {
        smallestLength = Math.min(smallestLength, j - i + 1);
        break;
      }
    }
  }
  
  return smallestLength;
}
```

**Issue**: Checks every starting position → O(n²)

## Approach 2: Variable Window - O(n)

```javascript
function smallestSubarray(target, arr) {
  let smallestLength = Infinity;
  let windowSum = 0;
  let left = 0;
  
  for (let right = 0; right < arr.length; right++) {
    windowSum += arr[right];  // Expand window
    
    while (windowSum >= target) {
      // Found a valid window
      let length = right - left + 1;
      smallestLength = Math.min(smallestLength, length);
      
      windowSum -= arr[left];  // Shrink window
      left++;
    }
  }
  
  return smallestLength;
}
```

**Advantage**: Single pass → O(n)

### Dry Run

```
arr = [2, 3, 1, 2, 4, 3], target = 7

right=0: sum=2, (2<7 continue)
right=1: sum=5, (5<7 continue)
right=2: sum=6, (6<7 continue)
right=3: sum=8, (8≥7 found!) length=4
        shrink: sum=6, left=1
right=4: sum=10, (10≥7 found!) length=3
        shrink: sum=7, left=2, length=3
        shrink: sum=6, left=3 (6<7 stop)
right=5: sum=9, (9≥7 found!) length=3
        shrink: sum=7, left=4, length=2 ✓ MINIMUM
        shrink: sum=3, left=5 (3<7 stop)

Result: 2 ✓
```

# Node.js Streams & HighWaterMark

### Concept

`highWaterMark`: Buffer size limit for reading streams (typically 64KB).

### Use Case

```javascript
const fs = require('fs');

// Read large file in chunks
const stream = fs.createReadStream('large-file.txt', {
  highWaterMark: 64 * 1024  // 64KB chunks
});

stream.on('data', (chunk) => {
  console.log(`Chunk received: ${chunk.length} bytes`);
});
```

### Real-World: Search API

Similar to variable window: read stream data until you find a keyword, then stop processing.
