# Function Breakdown

## Function: isAnagram()

### Purpose
Check if two strings are anagrams (same characters, different order).

### Logic

```javascript
function isAnagram(s, t) {
  // Anagrams must be same length
  if (s.length !== t.length) return false;
  
  // Create frequency array (256 chars in ASCII)
  let array = new Array(256).fill(0);
  
  // Increment count for each char in s
  for (let i = 0; i < s.length; i++) {
    array[s[i].charCodeAt(0)]++;
  }
  
  // Decrement count for each char in t
  for (let i = 0; i < t.length; i++) {
    array[t[i].charCodeAt(0)]--;
  }
  
  // Check if all counts are 0
  for (let i = 0; i < array.length; i++) {
    if (array[i] > 0) return false;
  }
  
  return true;
}
```

### Dry Run

**Input**: `isAnagram("abecde", "aebecd")`

```
Step 1: Length check - both 6 ✓
Step 2: Create array of 256 zeros

Step 3: Process "abecde"
  'a' (97): array[97] = 1
  'b' (98): array[98] = 1
  'e' (101): array[101] = 1
  'c' (99): array[99] = 1
  'd' (100): array[100] = 1
  'e' (101): array[101] = 2

Step 4: Process "aebecd"
  'a' (97): array[97]-- = 0
  'e' (101): array[101]-- = 1
  'b' (98): array[98]-- = 0
  'e' (101): array[101]-- = 0
  'c' (99): array[99]-- = 0
  'd' (100): array[100]-- = 0

Step 5: Check all zeros - all are 0 ✓

Return: true
```

### Complexity Analysis

**Time**: O(n) - process each string once
**Space**: O(1) - array of fixed size 256 (constant)

# Event Loop Deep Dive

## Execution Example

```javascript
console.log("A");

setTimeout(() => {
  console.log("B");
}, 0);

Promise.resolve().then(() => {
  console.log("C");
});

console.log("D");
```

### Output Order: A → D → C → B

### Why This Order?

```
Phase 1: SYNCHRONOUS (Call Stack)
  console.log("A")    → Prints "A"
  setTimeout(...)     → Schedules to MACROTASK queue
  Promise.then(...)   → Schedules to MICROTASK queue
  console.log("D")    → Prints "D"
  Call Stack Empty!

Phase 2: MICROTASK Queue (Higher Priority)
  Promise.then()      → Prints "C"
  Microtask Empty!

Phase 3: MACROTASK Queue
  setTimeout()        → Prints "B"
```

## Async/Await Example

```javascript
async function myFunc() {
  console.log("1");       // Sync
  await Promise.resolve();  // Pause here
  console.log("2");       // Resume in microtask
}

console.log("3");    // Sync
myFunc();            // Sync start
console.log("4");    // Sync
```

### Output Order: 3 → 1 → 4 → 2

### Explanation

```
Sync Phase:
  "3" - console.log directly
  myFunc() - start execution
    "1" - console.log inside async
    await - pause (goes to microtask)
  "4" - next sync code

Microtask Phase:
  await resolution - continue myFunc
    "2" - resume after await
```

# Event Loop Architecture

```
┌─────────────────────────────────────┐
│         Call Stack                  │
│  (Execute synchronous code)         │
└─────────────────────────────────────┘
              ↓↑
┌─────────────────────────────────────┐
│      Microtask Queue                │
│  (Promises, async/await)            │
│  (Higher Priority)                  │
└─────────────────────────────────────┘
              ↓↑
┌─────────────────────────────────────┐
│      Macrotask Queue                │
│  (setTimeout, setInterval)          │
│  (Lower Priority)                   │
└─────────────────────────────────────┘
```

**Rule**: Call Stack → All Microtasks → One Macrotask → repeat

### Event Loop Key Concepts

- Promises/async = microtask queue
- setTimeout = macrotask queue
