Sliding Window Pattern Explained

What is Sliding Window?

Core Idea: Instead of recalculating the entire sum for each window, we add the new element entering and subtract the old element leaving. This reduces complexity from O(n²) to O(n).

Use Cases: Finding max/min in subarrays, average of subarrays, longest subarray with condition, shortest subarray with condition.

Visual Example: Sliding Window Animation

Function: maxSum(arr, k)

function maxSum(arr, k) {
  if (arr.length < k) return "Invalid Input";

  // Calculate first window sum
  let sum = 0;
  for (let i = 0; i < k; i++) {
    sum += arr[i];
  }

  let temp = sum;  // Track current window sum
  let i = k;       // Start from k-th element

  // Slide window: add new element, remove old element
  while (i < arr.length - 1) {
    temp = temp - arr[i - k] + arr[i];  // KEY: Remove & Add
    if (temp > sum) {
      sum = temp;  // Update maximum
    }
    i++;
  }

  return sum;
}

Step-by-Step Dry Run

Input: maxSum([1, 2, 3, 4, 5], 3) Initial Setup: ├─ k = 3 (window size) ├─ Array length = 5 (valid: 5 >= 3) └─ Need to find max sum of 3 consecutive elements Step 1: Calculate First Window [1, 2, 3] ├─ sum = 0 ├─ Loop i=0: sum = 1 ├─ Loop i=1: sum = 3 ├─ Loop i=2: sum = 6 └─ First window sum = 6, temp = 6, i = 3 Step 2: Slide Window to [2, 3, 4] ├─ Condition: 3 < 4? YES (i < arr.length - 1) ├─ Remove arr[0]=1, Add arr[3]=4 ├─ temp = 6 - 1 + 4 = 9 ├─ temp (9) > sum (6)? YES ├─ sum = 9 └─ i = 4 Step 3: Slide Window to [3, 4, 5] ├─ Condition: 4 < 4? NO (loop ends) ├─ Window [3, 4, 5] would sum to 12 but not checked └─ Return: 9 Correct Answer: 12 (Window [3, 4, 5])

Complexity Analysis

Time Complexity

O(n)

Space Complexity

O(1)

Node.js Buffers Deep Dive

What is a Buffer?

Definition: Raw binary data (0s and 1s). Strings use UTF-16 encoding (heavy); Buffers use raw bytes (efficient).

Why? Strings are designed for text; Buffers handle any binary data (images, videos, network packets, file I/O).

Buffer Example

const buf = Buffer.from("Hi Navi");
console.log(buf);           // 
console.log(buf.toString()); // "Hi Navi"
console.log(buf.toJSON());   // { type: 'Buffer', data: [...] }

When to Use Buffers

Use Case Why Buffers Example
Binary Data Handles any byte patterns, not just text Image files, executable files
Memory Efficiency No encoding overhead, raw bytes Processing large files in chunks
Network Operations TCP/UDP sockets transmit bytes Reading from sockets, HTTP responses
File I/O Disk storage is binary Reading/writing files with streams

Key Advantages

  • Handles Any Binary Data: Images, videos, audio, executable files
  • More Memory Efficient: No UTF-16 encoding overhead
  • Faster for Large Data: Reduced memory footprint
  • Trade-off: Not human-readable without conversion
