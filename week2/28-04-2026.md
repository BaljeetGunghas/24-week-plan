# Key Sections

## Part 1: Sliding Window Explanation

**Interview Answer:**
"The sliding window pattern allows us to track a subset of data without recalculating the entire sum. By adding the new element entering and subtracting the old element leaving, we reduce complexity from O(n²) to O(n)."

## Part 2: Maximum Sum of K Consecutive Elements

### Function

```javascript
function maxSum(arr, k) {
  if (arr.length < k) return "Invalid Input";
  
  // Calculate first window
  let sum = 0;
  for (let i = 0; i < k; i++) {
    sum += arr[i];
  }
  
  let temp = sum;
  let i = k;
  
  // Slide window
  while (i < arr.length - 1) {
    temp = temp - arr[i - k] + arr[i];
    if (temp > sum) {
      sum = temp;
    }
    i++;
  }
  
  return sum;
}
```

### Complexity: O(n) time, O(1) space

## Part 3: Node.js Buffers

### What is a Buffer?

Raw binary data (0s and 1s). Strings are UTF-16 (heavy); Buffers are raw bytes (efficient).

### Example

```javascript
const buf = Buffer.from("Hi Navi");
console.log(buf);  // <Buffer 48 69 20 4e 61 76 69>
console.log(buf.toString());  // "Hi Navi"
console.log(buf.toJSON());    // { type: 'Buffer', data: [...] }
```

Each character converted to ASCII decimal:
- H = 72
- i = 105
- (space) = 32
- etc.

### Why Buffers Matter

- ✅ Handle binary data (images, videos, network packets)
- ✅ More memory-efficient than strings
- ✅ Faster for large data
- ❌ Not human-readable
